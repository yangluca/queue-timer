到達 0 ・ 結帳完 0
目前排隊 0 人
怎麼用（第一次請先看）
  1. 到現場後，有顧客加入隊伍就按藍色「有人來了」。
  2. 有顧客結帳完成離開櫃檯就按綠色「結帳完成」。
  3. 看到人多直接走掉、沒排隊的人，按「看到人多就走掉」。
  4. 按錯就按「復原上一下」，會刪掉最後一筆。
  5. 觀察完按「傳給自己」用 LINE 傳到電腦，或按「複製資料」，再貼到 Excel。資料是三欄：編號、到達時間、結束時間（第 n 個到達配第 n 個結帳完，也就是先到先服務）。
資料只存在這支手機的這個瀏覽器裡，不會上傳。關掉分頁再打開資料還在，但換手機、換瀏覽器或清除瀏覽紀錄就沒了，記完請馬上傳出備份。iPhone 請用 Safari 打開；不要用 LINE 內建瀏覽器記錄，它可能不保留資料。
